# FranchiseTrack (FT) — Verified Franchise Discovery & Management Platform

A modern, high-performance web platform connecting ambitious entrepreneurs and investors with verified franchise opportunities worldwide. Built with a clean, trustworthy design language, intuitive investment analytics, and interactive application workflows.

---

## 🌟 Core Features

- **🔍 Franchise Discovery & Search**: Filter across categories (Food & Beverage, Fitness, EdTech, Automotive, Retail, Logistics), investment ranges, ROI tiers, payback periods, and territory availability.
- **📊 Interactive Pro-Forma & ROI Calculator**: Model monthly cashflows, royalty rates, break-even timelines, and customized revenue projections dynamically.
- **⚖️ Side-by-Side Comparison Matrix**: Compare up to 4 franchise brands simultaneously across key metrics, liquid capital requirements, royalty fees, and growth ratings.
- **📝 Multi-Step Franchise Application**: Seamless 4-step investor intake flow with instant validation, territory preference selection, and application reference ID generation.
- **📁 Investor Dashboard & Tracker**: Real-time status tracking for submitted applications, milestone progressions, and bookmarked opportunities.
- **🏢 Brand Portal & Admin Console**: Management views for listing new franchise brands, reviewing applicant pipelines, and managing inquiries.
- **📱 Responsive & Accessible**: Mobile-first design using muted sage green, warm off-white, and pale blue palettes with smooth micro-interactions.

---

## 🛠️ Technology Stack

- **Framework**: [React 19](https://react.dev/) + [Vite 8](https://vite.dev/)
- **Routing**: [React Router 7](https://reactrouter.com/) (SPA with client-side history)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Visuals**: [Canvas Confetti](https://www.npmjs.com/package/canvas-confetti)
- **Styling**: Pure Modern CSS with custom design system variables
- **Deployment**: [Vercel](https://vercel.com/) with SPA rewrite rules

## 🚀 Getting Started

### Prerequisites

Ensure you have [Node.js](https://nodejs.org/) (v18 or higher) installed on your system.

### Installation

```bash
# Clone the repository
git clone https://github.com/Om1120/ft.git

# Navigate into the project folder
cd ft

# Install dependencies
npm install
```

### Development Server

```bash
npm run dev
```

Open `http://localhost:5180` in your browser to view the application.

### Production Build

```bash
npm run build
```

The optimized static assets will be generated in the `dist/` directory.

### Preview Production Build

```bash
npm run preview
```
